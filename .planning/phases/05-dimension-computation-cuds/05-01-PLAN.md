    Follow codebase conventions: module docstring, logging setup, section banners, PEP 8, type hints, pathlib.

    Module-level constants:
    ```python
    # Dimension mapping: panel_column -> dimension_key
    # Each entry: (panel_col, dim_key, invert, needs_rate_computation)
    DIMENSION_MAP = [
        ("ifgf_geral",                   "D1", False, None),

        ("total_beds",                   "D7", False, ("populacao", 10_000)),  # beds per 10k pop
        ("health_expenditure_per_capita","D9", False, None),
    ]
    EPSILON = 0.01  # Floor offset for geometric mean
    ```

    Public functions:

    1. `compute_all_dimensions(panel: pd.DataFrame) -> pd.DataFrame`:
       - Takes the assembled panel (cod_ibge, year, + all source columns)
       - Creates a new DataFrame with (cod_ibge, year, D1, D2, ..., D7, D9)
       - For D7: compute `total_beds / populacao * 10_000` (beds per 10,000 inhabitants). Use `populacao.replace(0, np.nan)` to avoid division by zero.
       - For D4 (inverted): value is kept as-is here -- inversion happens AFTER normalization in normalize_within_year()
       - Returns DataFrame with raw (unnormalized) dimension values

    2. `normalize_within_year(dims: pd.DataFrame) -> pd.DataFrame`:
       - Groups by 'year', applies min-max normalization to each D* column using `groupby('year').transform()`
       - For each dimension column: `(x - x_min) / (x_max - x_min)`. If x_max == x_min (constant), assign 0.5.
       - For D4 (inverted): after min-max normalization, compute `1 - normalized_value` so higher SUS dependence -> lower score
       - NaN values preserved (not filled)
       - Returns DataFrame with normalized [0,1] dimension values

    3. `compute_cuds(dims: pd.DataFrame) -> pd.Series`:
       - For each row: count non-NaN dimensions (n_dimensions), add epsilon to each normalized score, compute geometric mean = (product of (score + epsilon))^(1/n_dimensions) - epsilon
       - Specifically: `cuds = np.exp(np.log(scores + EPSILON).mean()) - EPSILON` per row (using only non-NaN scores)
       - If all dimensions NaN, cuds = NaN
       - No municipality should score exactly 0.0 CUDS (the epsilon floor prevents this)
       - Returns Series of CUDS values

    4. `persist_dimension_scores(dims: pd.DataFrame, db_path: Path) -> int`:
       - Connects to SQLite at db_path
       - Calls `create_schema(conn)` from build_database_v3 to ensure dimension_scores table exists
       - Uses `df.to_sql('dimension_scores', conn, if_exists='replace', index=False)`
       - Rebuilds PK after replace (same pattern as build_database_v3.py load_panel)
       - Returns row count
       - Logs: dimension count summary, CUDS distribution stats (mean, median, min, max), cross-sectional dimension flags

    5. `main(argv=None) -> int`:
       - CLI entry point with argparse: `--db-path` (default: database/icskg_br.sqlite), `--log-file` (optional computation log)
       - Reads panel from SQLite municipal_health table: `pd.read_sql("SELECT * FROM municipal_health", conn)`
       - Calls compute_all_dimensions -> normalize_within_year -> compute_cuds
       - Adds cuds and n_dimensions columns to dims DataFrame
       - Calls persist_dimension_scores
       - Logs cross-sectional dimension annotation: "D3 (IDHM 2010) and D5 (Census 2022 sanitation) are cross-sectional -- they do not represent genuine temporal variation" (per DIMS-04)
       - Optionally writes computation log JSON with: dimension_count, normalization_method, cuds_method, epsilon, cross_sectional_flags, distribution_stats
