    **Create tests/test_compute_lcogs.py** with 12 tests using synthetic DataFrames.

    **Create analysis/compute_lcogs.py** with the following functions:

    1. **_haversine_km(lat1, lon1, lat2, lon2)** -- Vectorized haversine distance in km. Pure numpy, no external dependency. Uses the standard formula: 2 * R * arcsin(sqrt(sin^2(dlat/2) + cos(lat1)*cos(lat2)*sin^2(dlon/2))) with R=6371 km.

    2. **_load_municipality_centroids(db_path)** -- Load municipality centroid coordinates. Strategy (Claude's discretion per CONTEXT.md): use geobr package if available to get municipality centroids from IBGE 2022 shapefiles. Fallback: read from a centroids CSV if bundled. The function returns a DataFrame with (cod_ibge, lat, lon). Cache the result in a module-level variable to avoid re-downloading. If geobr is not available, log a warning and use the IBGE API for municipality coordinates, or raise FileNotFoundError with guidance to install geobr (`pip install geobr`).

    3. **compute_lcogs1(panel, facilities_df, centroids_df)** -- LCoGS-1: Access to bellwether procedures (per LCOG-01).
       - Filter facilities_df to is_bellwether == True
       - Get unique bellwether municipality codes
       - For each municipality in panel, compute haversine distance to nearest bellwether municipality using centroids
       - Municipalities that contain a bellwether facility get distance 0.0
       - Output column: lcogs1_distance_km
       - Compute for all years (geocoordinates are static -- same distance every year)

    4. **compute_lcogs2(panel, professionals_df)** -- LCoGS-2: SAO workforce density (per LCOG-02).
       - professionals_df already deduplicated by (cns_prof, cod_ibge, year) in extraction
       - Count SAO professionals per (cod_ibge, year)
       - Merge with panel to get population
       - sao_per_100k = n_sao / populacao * 100_000
       - Log deduplication count (total professionals before/after if re-dedup needed, or just the count used)
       - Guard against zero population with np.nan

    5. **compute_lcogs3(panel)** -- LCoGS-3: Surgical volume per 100,000 (per LCOG-03).
       - Read procedure count from panel. Try column names in order: "n_procedures", "procedure_count", "aih_count"
       - surgical_volume_per_100k = n_procedures / populacao * 100_000
       - Label as SUS-funded procedures only (comment in code)

    6. **compute_lcogs4(panel)** -- LCoGS-4: Perioperative mortality rate (per LCOG-04).
       - Read death count from panel. Try column names: "n_deaths", "deaths"
       - Read procedure count from panel (same logic as LCoGS-3)
       - pomr = n_deaths / n_procedures
       - Where n_procedures < 10, set pomr = NaN (unstable rate suppression per CONTEXT.md)
       - Document: "POMR = in-hospital deaths within surgical admissions (SUS-funded)"

    7. **compute_lcogs5(panel)** -- LCoGS-5: Financial risk protection (per LCOG-05).
       - Read total cost from panel. Try columns: "total_cost_brl", "total_value"
       - Read procedure count for mean cost computation
       - mean_procedure_cost = total_cost / n_procedures
       - financial_risk_ratio = mean_procedure_cost / gdp_per_capita
       - Both numerator and denominator already in constant 2023 BRL (deflated in Phase 4)
       - Guard against zero GDP per capita or zero procedures

    8. **compute_lcogs6(panel)** -- LCoGS-6: Catastrophic expenditure proxy (per LCOG-06).
       - This is an ecological-level proxy (not individual household)
       - Threshold (Claude's discretion per CONTEXT.md): define CATASTROPHIC_THRESHOLD = 0.10 (10% of annual GDP per capita)
       - For each municipality-year: compute mean procedure cost, flag as catastrophic if mean_procedure_cost > gdp_per_capita * CATASTROPHIC_THRESHOLD
       - catastrophic_expenditure = int(mean cost > threshold, 0 otherwise) since we only have aggregates in the panel
       - Guard against zero GDP or procedures

    9. **compute_all_lcogs(panel, facilities_df, professionals_df, centroids_df)** -- Orchestrator. Calls all 6 functions, merges results into single DataFrame with columns: cod_ibge, year, lcogs1_distance_km, sao_per_100k, surgical_volume_per_100k, pomr, financial_risk_ratio, catastrophic_expenditure.

    10. **persist_lcogs_indicators(lcogs_df, db_path)** -- Write to SQLite lcogs_indicators table.

        ```sql
            PRIMARY KEY (cod_ibge, year)
        );
        ```
