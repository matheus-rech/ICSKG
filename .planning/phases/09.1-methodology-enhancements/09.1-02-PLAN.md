Per METH-02. Create analysis/age_standardization.py following codebase conventions (PEP 8, %-format logging, section banners, argparse CLI):

1. Module-level docstring explaining direct age-standardization of surgical rates using IBGE standard age bands.

2. Constants:
   - AGE_BANDS: list of tuples defining standard 5-year age groups: [(0,4), (5,9), (10,14), ..., (75,79), (80, None)]
   - AGE_BAND_LABELS: ["0-4", "5-9", ..., "75-79", "80+"]
   - COD_IDADE_MAP: {4: "years", 3: "months", 2: "days", 1: "hours"} -- SIH age unit codes

3. Functions:

   a) `fetch_ibge_age_sex_population(years: range, base_dir: Path | None = None) -> pd.DataFrame`:
      - Use sidrapy to fetch IBGE SIDRA table 6579 (or 9514 for Census 2022) with age groups and sex breakdown
      - If SIDRA unavailable, try loading from data_sources/reference/age_sex_population.parquet
      - Return DataFrame with columns: cod_ibge, year, age_band, sex, population
      - sex values: "M" (male), "F" (female), "T" (total)
      - age_band values: match AGE_BAND_LABELS
      - Log row counts and coverage

   b) `_resolve_age_years(idade: pd.Series, cod_idade: pd.Series) -> pd.Series`:
      - Convert SIH IDADE + COD_IDADE to age in years
      - COD_IDADE=4 -> age=IDADE (already years)
      - COD_IDADE=3 -> age=IDADE/12 (months to years)
      - COD_IDADE=2 -> age=0 (days = infant)
      - COD_IDADE=1 -> age=0 (hours = neonate)
      - Return age in years as float

   c) `_assign_age_band(age_years: pd.Series) -> pd.Series`:
      - Map continuous age to AGE_BAND_LABELS using pd.cut with bins derived from AGE_BANDS
      - Return categorical series with age band labels

   d) `compute_age_standardized_rates(sih_dir: Path, pop_df: pd.DataFrame, years: range, db_path: Path | None = None) -> pd.DataFrame`:
      - Read procedure-level SIH Parquet files from sih_dir (glob *.parquet)
      - Resolve age to years using _resolve_age_years(IDADE, COD_IDADE)
      - Assign age bands using _assign_age_band
      - Extract sex from SEXO column (1="M", 3="F" per SIH encoding, or string "M"/"F")
      - Group by (cod_ibge, year, age_band, sex) to get procedure counts and death counts
      - Merge with pop_df to get age-sex-specific population denominators
      - Compute age-specific rates: procedures_per_100k = count / population * 100_000
      - Compute age-specific mortality rates: deaths_per_100k = deaths / population * 100_000
      - Direct standardization: use Brazil national age structure as standard population (sum across all municipalities for each age-sex group)
      - Compute age-standardized rate per municipality-year-sex as weighted sum of age-specific rates
      - Return DataFrame: cod_ibge, year, sex, age_std_surgical_rate, age_std_mortality_rate, crude_surgical_rate, crude_mortality_rate
      - Also produce "T" (total, both sexes combined) rows

   e) `main(argv=None) -> int`:
      - Argparse: --sih-dir, --db-path, --out-dir, --start-year, --end-year
      - Fetch population data, compute age-standardized rates
      - Save to out_dir/age_standardized_rates.csv
      - Save gender-stratified summary to out_dir/tables/gender_stratified_rates.csv
      - Log summary statistics

4. Handle edge cases: municipalities with zero population in an age band (NaN rate), missing SEXO values (exclude from gender stratification but include in total).

**Part A: Health Region Crosswalk (database/health_regions.py)**

Create database/health_regions.py following codebase conventions:

1. Module-level docstring explaining health region (Regiao de Saude) aggregation for ~450 regions.

2. Constants:
   - HEALTH_REGION_URL: IBGE or DATASUS source URL for health region crosswalk
   - FALLBACK_PATH: data_sources/reference/health_regions.csv

3. Functions:

   a) `load_health_region_crosswalk(cache_dir: Path | None = None) -> pd.DataFrame`:
      - Try downloading from IBGE SIDRA or DATASUS (tabnet.datasus.gov.br/cgi/ibge/cnv/listas_munic.htm)
      - Fallback: load from data_sources/reference/health_regions.csv if it exists
      - Last resort: generate crosswalk from IBGE municipality codes (first 4 digits = microregion, or use CIR/CISR mapping)
      - Return DataFrame: cod_ibge (str, 7-digit), health_region_code (str), health_region_name (str), uf (str)
      - Log number of health regions found (~438-450 expected)

   b) `aggregate_by_health_region(panel: pd.DataFrame, crosswalk: pd.DataFrame) -> pd.DataFrame`:
      - Merge panel with crosswalk on cod_ibge
      - Group by (health_region_code, health_region_name, year)
      - For rate variables (sao_per_100k, surgical_volume_per_100k, etc.): compute population-weighted mean
      - For count variables (n_procedures, n_deaths, populacao): sum
      - For dimension scores (D1-D9, cuds): population-weighted mean
      - For distance (lcogs1_distance_km): population-weighted mean
      - For binary (catastrophic_expenditure): population-weighted mean (proportion)
      - Return health-region-year panel

   c) `main(argv=None) -> int`:
      - Argparse: --db-path, --out-dir
      - Load crosswalk, load panel from SQLite, aggregate
      - Save health_region_panel.csv to out_dir/tables/
      - Persist to SQLite health_region_indicators table
