<decisions>
## Implementation Decisions

### EconML Causal Inference (METH-01)
- Add econml to pyproject.toml dependencies
- Double Machine Learning (DML) — estimate causal effect of CUDS on each LCoGS outcome
- Causal Forest — heterogeneous treatment effects across municipalities
- CATE (Conditional Average Treatment Effect) estimation by region/population size
- Treatment variable: CUDS; Outcomes: 6 LCoGS indicators; Controls: region, population, year

### Age-Standardized Rates (METH-02)
- Download IBGE population by standard age bands (0-4, 5-9, ..., 75-79, 80+) from SIDRA
- Download population by sex from SIDRA
- Direct age-standardization of surgical rates, mortality rates per 100,000
- Gender-stratified analysis for all indicators
- SIH already has SEXO, IDADE, COD_IDADE columns in procedure-level Parquet

### Health Region Aggregation (METH-03)
- Map ~450 Regiões de Saúde from CNES or IBGE health region lookup
- Aggregate all indicators at health region level in addition to municipality level
- Include health region as an analysis unit in regressions and visualizations

### PCA Composite Score (METH-04)
- PCA on 8 CIMI dimension scores
- First principal component as alternative composite
- Compare PCA composite vs CUDS geometric mean (correlation, ranking agreement)
- Report PCA loadings showing which dimensions drive the most variance

### USD Conversion (METH-05)
- Apply BRL→USD conversion using average 2023 exchange rate from BCB
- All monetary values (GDP per capita, health expenditure, procedure costs) available in both BRL and USD
- Exchange rate sourced from BCB SGS API or SIDRA

### Confidence Intervals + Dispersion (METH-06)
- Every summary statistic must include SD/SE or IQR plus 95% CI
- Regression outputs: already have SE and CI from PanelOLS
- Rates: Wilson score interval or Poisson CI
- ML metrics: mean ± SD across CV folds with 95% CI
- Descriptive tables: mean ± SD (95% CI) or median (IQR)

### Network Distance Metrics (METH-07)
- Summarize MUNIC_RES→MUNIC_MOV haversine distances per municipality-year
- Mean/median travel distance for surgical care
- % patients treated in their own municipality vs referred elsewhere
- Patient flow network already built in Phase 9 — extract summary statistics

### Claude's Discretion
- EconML model hyperparameters and treatment variable discretization
- Which SIDRA table for age/sex population breakdown
- Health region crosswalk source (CNES vs IBGE vs DataSUS)
- BCB exchange rate API endpoint
- Whether to create separate scripts or extend existing analysis modules

</decisions>
