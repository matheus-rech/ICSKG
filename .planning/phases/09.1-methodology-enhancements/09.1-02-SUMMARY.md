## Files Created/Modified
- `analysis/age_standardization.py` - Direct age-standardization with COD_IDADE resolution, gender stratification (M/F/T), CLI entry point

## Decisions Made
- Direct age-standardization (not indirect) chosen because it uses the same standard population weights across all municipalities, enabling valid cross-municipality comparison
- SIH SEXO encoding handled for both integer (1/3) and string ("M"/"F") formats for robustness
- Health region crosswalk uses 3-tier fallback: cached CSV > DATASUS download > IBGE microregion proxy, ensuring pipeline never blocks on network availability
- BCB exchange rate fetched from SGS API series 3698 (PTAX selling daily rate, averaged annually); hardcoded 4.9942 BRL/USD fallback for 2023 ensures offline operation
- USD columns use `{col}_usd` suffix pattern, preserving original BRL columns unchanged
