**Part A: Create analysis/reporting.py**

Follow codebase conventions (PEP 8, %-format logging, section banners, argparse CLI, module-level docstring).

1. Module-level docstring explaining confidence interval and dispersion computation for all ICSKG-BR output types.

2. Functions:

   a) `mean_ci(values: np.ndarray, confidence: float = 0.95) -> dict`:
      - Compute mean, SD, SE, and confidence interval for a numeric array
      - Use scipy.stats.t.interval for t-distribution CI (appropriate for small n like CV folds)
      - Return dict: {"mean": float, "sd": float, "se": float, "ci_lower": float, "ci_upper": float, "n": int}
      - Handle edge cases: n=0 returns all NaN, n=1 returns mean with NaN CI

   b) `median_iqr(values: np.ndarray) -> dict`:
      - Compute median, Q1 (25th), Q3 (75th), IQR
      - Return dict: {"median": float, "q1": float, "q3": float, "iqr": float, "n": int}

   c) `wilson_ci(successes: int, trials: int, confidence: float = 0.95) -> dict`:
      - Wilson score interval for proportions (better than Wald for small samples)
      - Use scipy.stats.norm.ppf for z-value
      - Return dict: {"proportion": float, "ci_lower": float, "ci_upper": float}
      - Handle edge cases: trials=0 returns NaN

   d) `poisson_ci(count: int, person_time: float, confidence: float = 0.95) -> dict`:
      - Exact Poisson confidence interval for rates
      - Use scipy.stats.poisson or chi2 method: lower = chi2.ppf(alpha/2, 2*count) / (2*person_time), upper = chi2.ppf(1-alpha/2, 2*(count+1)) / (2*person_time)
      - Return dict: {"rate": float, "ci_lower": float, "ci_upper": float}

   e) `add_ci_to_descriptives(df: pd.DataFrame, value_cols: list[str], group_cols: list[str]) -> pd.DataFrame`:
      - Group by group_cols, compute mean_ci and median_iqr for each value_col
      - Return wide DataFrame: group_cols + {col}_mean, {col}_sd, {col}_ci_lower, {col}_ci_upper, {col}_median, {col}_iqr, {col}_n for each col
      - Used for descriptive statistics tables

   f) `add_ci_to_rates(df: pd.DataFrame, count_col: str, pop_col: str, multiplier: float = 100_000) -> pd.DataFrame`:
      - For each row, compute rate = count/pop * multiplier
      - Compute Poisson CI for each rate
      - Add columns: rate, rate_ci_lower, rate_ci_upper
      - Used for age-standardized rates from Plan 02

   g) `generate_descriptive_table(db_path: Path, out_dir: Path) -> Path`:
      - Load dimension_scores + lcogs_indicators + municipality_lookup from SQLite
      - Compute mean +/- SD (95% CI) for CUDS and all 6 LCoGS indicators
      - Compute by region (5 macro-regions) and overall
      - Save as out_dir/tables/descriptive_stats_with_ci.csv
      - Format: variable, region, n, mean, sd, ci_lower, ci_upper, median, iqr

   h) `main(argv=None) -> int`:
      - Argparse: --db-path, --out-dir
      - Call generate_descriptive_table
      - Log summary

Per METH-07. Create analysis/network_distances.py following codebase conventions (PEP 8, %-format logging, section banners, argparse CLI):

1. Module-level docstring explaining network distance analysis: summarizes haversine distances between municipality of residence (MUNIC_RES / cod_ibge_res) and municipality of treatment (MUNIC_MOV / cod_ibge) from SIH procedure-level data.

2. Constants:
   - PROCESSED_SIH_DIR: default path "data_sources/processed/sih/"
   - DISTANCE_COLS: columns needed from SIH Parquet: ["cod_ibge", "cod_ibge_res", "year", "N_AIH"]

3. Functions:

   a) `_load_centroids() -> dict[str, tuple[float, float]]`:
      - Reuse geobr centroid loading pattern from compute_lcogs.py
      - Return dict mapping cod_ibge -> (lat, lon)
      - Module-level cache to avoid re-downloading

   b) `_haversine_km(lat1, lon1, lat2, lon2) -> np.ndarray`:
      - Copy from spatial_analysis.py or compute_lcogs.py (same vectorised implementation)
      - This avoids a cross-module dependency that could break if spatial_analysis changes

   c) `compute_network_distances(sih_dir: Path, years: range | None = None) -> pd.DataFrame`:
      - Read all SIH Parquet files from sih_dir (glob *.parquet)
      - For each file, read only cod_ibge, cod_ibge_res, year columns (use columns= parameter for memory efficiency)
      - If cod_ibge_res not in columns (old format), try MUNIC_RES
      - Load municipality centroids via _load_centroids()
      - For each procedure row, compute haversine distance between residence and treatment municipality centroids
      - Classify each procedure: self_treated = (cod_ibge == cod_ibge_res), i.e., patient treated in their own municipality
      - Group by (cod_ibge, year) to produce per-municipality-year summaries:
        * n_procedures: total procedure count
        * n_self_treated: count where cod_ibge == cod_ibge_res
        * pct_self_treated: n_self_treated / n_procedures * 100
        * mean_distance_km: mean haversine distance for referred patients (excluding self-treated)
        * median_distance_km: median haversine distance for referred patients
        * p90_distance_km: 90th percentile distance for referred patients
        * max_distance_km: max haversine distance
      - For self-treated patients, distance = 0 (include in overall stats but exclude from referred-patient stats)
      - Return DataFrame: cod_ibge, year, n_procedures, n_self_treated, pct_self_treated, mean_distance_km, median_distance_km, p90_distance_km, max_distance_km

   d) `main(argv=None) -> int`:
      - Argparse: --sih-dir, --out-dir, --db-path (optional, to persist to SQLite)
      - Call compute_network_distances
      - Save to out_dir/tables/network_distances.csv
      - If --db-path provided, persist to SQLite table network_distance_metrics
      - Log summary: overall mean distance, overall pct_self_treated, municipalities covered

4. Performance consideration: SIH Parquet files can be large. Process year-by-year to limit memory. Use chunked reading if total exceeds ~10M rows. Log progress per year.

5. Edge cases:
   - Missing centroids for a municipality -> distance = NaN for those procedures
   - cod_ibge_res is NaN -> exclude from distance computation but count in n_procedures
   - Zero referred patients in a municipality-year -> mean_distance_km = NaN (no referrals)
