    Create `scripts/sih_extract.py` -- the ETLSIH CSV to Parquet processor. This REPLACES the DBC-reading logic in sih_batch_v2.py but keeps the same structural patterns (multiprocessing, idempotent output, column subsetting).

    **Module-level constants:**
    - `SIH_COLS_KEEP`: list of 27 column names (same as in RESEARCH.md SIH_COLS: UF_ZI, ANO_CMPT, MES_CMPT, N_AIH, IDENT, MUNIC_RES, MUNIC_MOV, NASC, SEXO, IDADE, COD_IDADE, DIAS_PERM, DIAG_PRINC, DIAG_SECUN, PROC_SOLIC, PROC_REA, DT_INTER, DT_SAIDA, MORTE, VAL_TOT, VAL_UTI, CNES, COMPLEX, FINANC, CAR_INT, ESPEC, CGC_HOSP)
    - `UF_CODES`: all 27 Brazilian state codes (same as sih_batch_v2.py)
    - `ETLSIH_FILE_PATTERN`: `"ETLSIH.ST_{uf}_{year}_{month}_t.csv"` for glob matching

    **Core functions:**

    1. `read_etlsih_csv(csv_path: Path, columns: list[str] | None = None) -> pd.DataFrame`:
       - Use DuckDB `read_csv_auto()` with SELECT for column projection (NOT pandas).
       - Default columns = SIH_COLS_KEEP.
       - Handle missing columns gracefully: if a column is not present in the CSV, log a warning and skip it (some months may have slightly different schemas).
       - Convert numeric columns after read: MORTE to int via `pd.to_numeric(errors="coerce").fillna(0).astype(int)`, VAL_TOT/VAL_UTI to float via `pd.to_numeric(errors="coerce")`, DT_INTER/DT_SAIDA keep as int (YYYYMMDD format -- do NOT convert to datetime here, that is downstream).
       - Return DataFrame.

    2. `_process_uf_month(uf: str, year: int, month: int, raw_dir: Path, output_dir: Path, skip_existing: bool = True) -> dict`:
       - Find CSV file at `raw_dir / f"ETLSIH.ST_{uf}_{year}_{month}_t.csv"`. If not found, try alternate patterns (month without zero-padding: `_1_t.csv` vs `_01_t.csv`).
       - Output path: `output_dir / f"{uf}_{year}{month:02d}.parquet"`.
       - If skip_existing and output exists with non-zero size, return early (idempotent).
       - Read CSV with `read_etlsih_csv()`.
       - Normalize MUNIC_MOV and MUNIC_RES using `normalize_cod_ibge()` from database.utils. Rename MUNIC_MOV to `cod_ibge` (treatment municipality per project decision). Keep MUNIC_RES as `cod_ibge_res` for future use.
       - Add `year` column from ANO_CMPT and `month` column from MES_CMPT.
       - Deduplicate by N_AIH (keep first).
       - Write to Parquet with snappy compression.
       - Return dict: `{"uf": uf, "status": "ok"|"skipped"|"not_found"|"error", "rows": N, "path": path}`.
       - Log progress with %-style formatting.

    3. `process_sih_month(year: int, month: int, raw_dir: Path, output_dir: Path, ufs: list[str] | None = None, workers: int = 1, skip_existing: bool = True) -> list[dict]`:
       - Process all UFs for a given year-month.
       - If workers > 1, use multiprocessing.Pool (same pattern as sih_batch_v2.py).
       - Returns list of result dicts from _process_uf_month.
       - Log summary: N/27 UFs ok, total rows.

    4. `main(argv=None) -> int`:
       - CLI interface: `--year-month YYYY-MM` or `--start YYYY-MM --end YYYY-MM`.
       - `--raw-dir` (defaults to config.yaml data_root or data_sources/raw).
       - `--output-dir` (defaults to data_sources/processed/sih/).
       - `--ufs` for specific states.
       - `--workers` for parallelism.
       - `--no-skip` to force reprocessing.
       - Load config via `load_config()` for NAS path resolution.

    **CRITICAL anti-patterns to avoid (from RESEARCH.md):**
    - Do NOT load all 235 columns -- always use DuckDB column projection.
    - Do NOT use pandas read_csv for large files -- use DuckDB.
    - Do NOT modify NAS files -- read-only access.
    - Do NOT hardcode NAS path -- resolve through config.yaml.
    - Do NOT convert DT_INTER/DT_SAIDA to datetime here -- keep as int for downstream.

    **Follow project conventions:**
    - Module docstring with purpose, outputs, usage examples.
    - PEP 8, 4-space indent, ~88 char line width.
    - %-style logger formatting (never f-strings in logger).
    - Section banners with `# ---------------------------------------------------------------------------`.
    - Private functions with underscore prefix.
    - Type hints on all function signatures.
    - `if __name__ == "__main__": sys.exit(main())` entry point.
