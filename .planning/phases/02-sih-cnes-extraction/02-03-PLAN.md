    ```python
    # CBO-2002 6-digit codes for SAO (Surgeons, Anesthesiologists, Obstetricians)
    # Source: ANS FHIR CodeSystem tuss-24 (verified 2026-04-01)
    # WARNING: Do NOT use 4-digit family codes (2231=ALL physicians, 2232=DENTISTS, 2235=NURSES)
    CBO_SURGEONS = {
        "225210",  # Medico cirurgiao cardiovascular
        "225215",  # Medico cirurgiao de cabeca e pescoco
        "225225",  # Medico cirurgiao geral
        "225230",  # Medico cirurgiao pediatrico
        "225235",  # Medico cirurgiao plastico

        "225203",  # Medico em cirurgia vascular
        "225260",  # Medico neurocirurgiao
        "225295",  # Medico cirurgiao da mao
    }
    CBO_ANESTHESIOLOGISTS = {"225151"}
    CBO_OBSTETRICIANS = {"225250"}
    CBO_SAO = CBO_SURGEONS | CBO_ANESTHESIOLOGISTS | CBO_OBSTETRICIANS

    CNES_ST_COLS = [
        "CNES", "CODUFMUN", "COMPETEN",
        "CENTRCIR", "CENTROBS",
        "QTLEITP1", "QTLEITP2", "QTLEITP3",
        "VINC_SUS", "TP_UNID", "LEITHOSP",
    ]
    ```

    **Core functions:**

    1. `filter_bellwether_facilities(df: pd.DataFrame) -> pd.DataFrame`:
       - Compute total_beds = QTLEITP1 + QTLEITP2 + QTLEITP3 (use pd.to_numeric with errors="coerce", fillna(0)).
       - is_bellwether = (CENTRCIR > 0) | (CENTROBS > 0) | (total_beds >= 10).
       - Add `total_beds` and `is_bellwether` columns.
       - Return the FULL DataFrame with new columns (do not filter -- let caller decide).
       - This allows downstream to use both bellwether and non-bellwether facilities.

    2. `_read_cnes_st_csv(csv_path: Path, columns: list[str] | None = None) -> pd.DataFrame`:
       - Read CNES ST CSV with DuckDB column projection (same pattern as SIH).
       - Default columns = CNES_ST_COLS.
       - Handle missing columns gracefully.
       - Convert numeric columns: CENTRCIR, CENTROBS, QTLEITP1/2/3 to int via pd.to_numeric(errors="coerce").fillna(0).astype(int).

    3. `_extract_from_zip(zip_path: Path, output_dir: Path, year_start: int = 2015, year_end: int = 2023) -> list[Path]`:
       - Open zip file, list entries matching pattern `ETLCNES.ST_*__{YY}_{MM}_t.csv`.
       - Filter to entries where YY is in range (year_start%100 to year_end%100).
       - Extract matching files to output_dir (preserving flat structure, no subdirectories).
       - Return list of extracted file paths.
       - Log progress: N files extracted out of M total in zip.
       - Use zipfile stdlib module.

    4. `extract_cnes_facilities(input_dir: Path, output_dir: Path, year: int, zip_path: Path | None = None) -> Path`:
       - If zip_path provided and input_dir is empty, call _extract_from_zip() first.
       - Glob all `ETLCNES.ST_*__{yy}_{mm}_t.csv` files in input_dir for the target year.
       - File pattern uses 2-digit year: `ETLCNES.ST_*__{year%100:02d}_*_t.csv`.
       - Read each file with _read_cnes_st_csv(), concatenate.
       - Rename CODUFMUN to cod_ibge via rename_municipality_column().
       - Normalize cod_ibge via normalize_cod_ibge().
       - Extract year from COMPETEN: `(pd.to_numeric(df["COMPETEN"], errors="coerce") // 100).astype(int)`.
       - Apply filter_bellwether_facilities().
       - Keep latest COMPETEN per (CNES, cod_ibge) to deduplicate monthly snapshots.
       - Rename columns to lowercase (cnes, cod_ibge, year, centrcir, centrobs, total_beds, is_bellwether, vinc_sus, tp_unid).
       - Run validate_dataframe() on the result.
       - Write to `output_dir / "facilities.parquet"` with snappy compression.
       - Return output path.
       - Log summary: N total facilities, M bellwether facilities.

    5. `main(argv=None) -> int`:
       - CLI: `--zip-path` (path to ETLCNES.zip), `--input-dir` (extracted CSVs), `--output-dir`, `--year`.
       - Load config for default paths.
       - Call extract_cnes_facilities().
