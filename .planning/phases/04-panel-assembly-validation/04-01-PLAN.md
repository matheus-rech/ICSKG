  <action>
    Create database/deflate_ipca.py with two public functions (per D-DATA-10):

    1. fetch_ipca_annual_index(years, base_year=2023) -> pd.DataFrame:
       - Use sidrapy.get_table(table_code="1737", territorial_level="1", ibge_territorial_code="all", variable="2266", period="all")
       - Parse: skip header row (index 0), extract year from D2C[:4], month from D2C[4:6], value from V column
       - Filter to December values only (month == 12) for annual index
       - Compute deflation_factor = index_dec_base_year / index_dec_year
       - Return DataFrame with [year, ipca_index, deflation_factor]
       - Use general IPCA (not health sub-index) per research recommendation; note in docstring that health sub-index is a sensitivity analysis option

    2. deflate_column(df, col, ipca_factors) -> pd.DataFrame:
       - Preserve original as {col}_nominal
       - Map year to deflation_factor via ipca_factors Series (year -> factor)
       - Multiply: df[col] = df[col] * df["year"].map(ipca_factors)
       - NaN values remain NaN (no special handling needed -- multiplication by NaN stays NaN)
       - Return modified DataFrame

    Create database/assemble_panel.py with public functions:

    1. build_panel_scaffold(years) -> pd.DataFrame:
       - Load ref from load_ibge_municipios() to get authoritative municipality list
       - For each year, create scaffold with ref[["cod_ibge"]].copy() + year column
       - Concat all years, assert len == len(ref) * len(years)
       - Return panel with columns [cod_ibge, year]

    2. load_source(name, path, years) -> pd.DataFrame:
       - Read Parquet file at path
       - Apply rename_municipality_column() then normalize_cod_ibge()
       - Apply apply_amc_crosswalk() per year for temporal harmonization
       - For cross-sectional sources (idhm, census_sanitation): replicate single-year row across all panel years with is_crosssectional=True flag
       - For empty/missing sources (SIOPS, RENAVAM may be empty): check len(df) > 0 and value columns have at least some non-NaN; if empty, log warning and return empty DataFrame (skip merge)
       - Return validated-ready DataFrame with [cod_ibge, year, ...value_cols]

    3. assemble_panel(processed_dir, years, quarantine_dir) -> tuple[pd.DataFrame, list[ValidationReport]]:
       - Build scaffold via build_panel_scaffold()
       - Define source catalog: dict mapping source_name -> (parquet_path, value_columns)
       - For each source: load_source() -> validate_dataframe(strict=False, quarantine_dir) -> left merge onto scaffold with validate="1:1"
       - Deflate monetary columns (gdp_per_capita, health_expenditure_per_capita) BEFORE merge using fetch_ipca_annual_index() + deflate_column()
       - Apply deflation to GDP source and SIOPS source DataFrames individually before they join the scaffold
       - After all merges: assert len(panel[panel.year == y]) == expected_per_year for every y in years
       - Write validation_report.json via write_validation_report()
       - Return (panel, reports)

    Follow project conventions: snake_case, logging with %-style formatting, pathlib.Path, section banner comments with dashes, type hints, docstrings.
