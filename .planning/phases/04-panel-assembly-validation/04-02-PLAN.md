  <action>
    Create database/impute_ifgf.py with two public functions (per PANL-05 and PANL-06):

    1. impute_ifgf_mice(panel, m=5, max_iter=10) -> tuple[pd.DataFrame, dict]:
       - Import IterativeImputer with experimental enabler: `from sklearn.experimental import enable_iterative_imputer  # noqa`
       - Import BayesianRidge from sklearn.linear_model
       - Define IFGF_COLS = ["ifgf_geral", "ifgf_ra", "ifgf_gp", "ifgf_id", "ifgf_el", "ifgf_sa"]
       - Define AUX_COLS = ["gdp_per_capita", "populacao", "region_code"]
       - If "region_code" not in panel.columns, derive it from "uf" column using UF-to-region mapping (N=1, NE=2, CO=3, SE=4, S=5)
       - Record mnar_mask = panel[IFGF_COLS].isna().any(axis=1) BEFORE imputation
       - If mnar_mask.sum() == 0, return (panel, log_with_zero_imputed) early
       - Build feature matrix X = panel[IFGF_COLS + AUX_COLS].copy()
       - Run m imputations with different random_state (i * 42 for i in range(m))
       - Each uses IterativeImputer(estimator=BayesianRidge(), sample_posterior=True, max_iter=max_iter, verbose=0)
       - Pool via Rubin's rules: mean across m imputations for IFGF columns only
       - Only overwrite IFGF values where original was NaN (mnar_mask rows)
       - Add ifgf_is_imputed column: 1 where any IFGF col was imputed, 0 otherwise
       - Build imputation_log dict with: m, max_iter, method string, n_imputed_rows, ifgf_cols, aux_cols, per_year breakdown
       - Return (panel, imputation_log)

    2. generate_missingness_report(panel, output_path) -> Path:
       - For each value column in the panel (excluding cod_ibge, year, metadata cols):
         - For each year in panel.year.unique():
           - Count n_total, n_observed, n_missing, pct_missing
           - Assign missingness_mechanism based on column name:
             - IFGF cols: "MNAR"
             - idhm*: "cross_sectional_2010"
             - pct_sanitation*, pct_water*: "cross_sectional_2022"
             - health_expenditure*: "source_unavailable" if 100% missing, else "MAR"
             - vehicles*: "source_unavailable" if 100% missing, else "MAR"
             - All others: "NA" if 0% missing, "MAR" otherwise
           - Assign handling_method:
             - MNAR: "multiple_imputation_m5"
             - cross_sectional*: "constant_fill"
             - source_unavailable: "documented_gap"
             - NA: "none"
             - MAR: "left_as_nan"
       - Write to output_path as CSV with columns: variable, year, n_total, n_observed, n_missing, pct_missing, missingness_mechanism, handling_method
       - Sort by variable, year
       - Return output_path

    Follow project conventions: snake_case, %-style logging, pathlib, section banners, type hints, docstrings. Use `# noqa: BLE001` for broad exception handling per codebase pattern.

    - Test missingness_report_format: verify CSV columns and MNAR/cross_sectional labels
    - Test missingness_report_fully_observed: column with 0% missing has mechanism "NA" and handling "none"

    1. create_schema(conn: sqlite3.Connection) -> None:
       - Execute all 5 CREATE TABLE IF NOT EXISTS DDL statements
       - Log table creation

    2. seed_dimension_metadata(conn: sqlite3.Connection) -> None:
       - INSERT OR REPLACE into dimension_metadata from CIMI_DIMENSIONS constant
       - Mark D3 (IDHM) as is_crosssectional=1, crosssectional_year=2010
       - Mark D5 (Census sanitation) as is_crosssectional=1, crosssectional_year=2022

    3. seed_municipality_lookup(conn: sqlite3.Connection) -> None:
       - Load ref from load_ibge_municipios()
       - Derive region from UF using standard UF-to-region mapping
       - INSERT OR REPLACE into municipality_lookup (cod_ibge, name, state_uf, region)
       - population column populated from panel data if available, else NULL

    4. seed_deflation_log(conn: sqlite3.Connection, ipca_df: pd.DataFrame) -> None:
       - INSERT OR REPLACE into deflation_log from the IPCA factors DataFrame (year, ipca_index, deflation_factor, base_year=2023)

    5. seed_imputation_log(conn: sqlite3.Connection, imputation_log: dict) -> None:
       - INSERT into imputation_log for each IFGF column + year combination from the log dict

    6. load_panel(conn: sqlite3.Connection, panel: pd.DataFrame) -> int:
       - Use panel.to_sql("municipal_health", conn, if_exists="replace", index=False)
       - NOT iterrows() -- batch insert per research anti-pattern guidance
       - Return row count inserted
       - Verify row count matches expected (5571 * n_years)

    7. build_database(panel, ipca_df, imputation_log, db_path, processed_dir) -> Path:
       - Orchestrator: create_schema -> seed_dimension_metadata -> seed_municipality_lookup -> seed_deflation_log -> seed_imputation_log -> load_panel
       - Write PANL-06-missingness.csv to processed_dir via generate_missingness_report() (imported from impute_ifgf)
       - Log final row count and table sizes
       - Return db_path

    8. main(argv=None) -> int:
       - CLI entry point with argparse
       - Args: --processed-dir, --db-dir, --years (start end)
       - Calls assemble_panel() then impute_ifgf_mice() then build_database()
       - This is the end-to-end Phase 4 orchestrator
