<objective>
Mint a Zenodo DOI for the ICSKG-BR processed dataset by mirroring the HuggingFace Dataset to a Zenodo deposition. Replace the placeholder fields in `.zenodo.json` with real author, institution, funder, and license metadata. The script supports both Zenodo Sandbox (free, used for validation) and production Zenodo (used at BMJ acceptance).

Purpose: HuggingFace Datasets are excellent for distribution but academia still expects a Zenodo or DataCite DOI for citation. Phase 11.5 establishes the HF→Zenodo mirroring path so that at BMJ acceptance, a single command publishes the dataset to Zenodo and mints a citable DOI. Until acceptance, the script is exercised against Zenodo Sandbox to prove it works without polluting production records.

Output: A working `scripts/mirror_to_zenodo.py`, a real `.zenodo.json`, and a Zenodo Sandbox deposition (DOI like `10.5072/zenodo.NNNNN`) that proves the mirror path is functional. Production deposit is deferred until BMJ accepts.

Zenodo API endpoints (via `requests`):
```
POST   https://sandbox.zenodo.org/api/deposit/depositions       (create empty)
POST   https://sandbox.zenodo.org/api/deposit/depositions/{id}/files       (upload one file)
PUT    https://sandbox.zenodo.org/api/deposit/depositions/{id}             (update metadata)
POST   https://sandbox.zenodo.org/api/deposit/depositions/{id}/actions/publish (publish + mint DOI)

For production: https://zenodo.org/api/...
Auth: Bearer token from https://(sandbox.)zenodo.org/account/settings/applications/tokens/new/
Required scope: deposit:write, deposit:actions
```

  <action>
1. **Create scripts/mirror_to_zenodo.py** with these functions:

   **`load_zenodo_metadata(zenodo_json: Path) -> dict`**
   - Reads `.zenodo.json`, parses JSON, validates required fields
   - Refuses to proceed if any value contains a placeholder marker like `[REAL INSTITUTION TO BE FILLED BY USER]` or `[Author Name]` or `[Institution]`
   - Returns the parsed metadata dict

   **`fetch_from_hf(repo_id: str, revision: str, target_dir: Path, hf_token: str | None = None) -> Path`**
   - Wraps `huggingface_hub.snapshot_download` (reuses Phase 11.2's pattern)
   - Returns the local path containing the parquet tree + manifest.json + README.md

   **`create_zenodo_deposition(metadata: dict, *, target: str, zenodo_token: str) -> dict`**
   - `target` is one of `"sandbox"` or `"production"` — selects base URL
   - POST to `/api/deposit/depositions` with empty body to create
   - Then PUT metadata via `/api/deposit/depositions/{id}` with `{"metadata": {...}}`
   - Returns the deposition dict (includes id, links, conceptdoi, doi-once-published)

   **`upload_files(deposition: dict, files_dir: Path, *, target: str, zenodo_token: str) -> list[dict]`**
   - Iterates files in `files_dir` (parquet, manifest, README, but skip .DS_Store etc.)
   - For each, POST multipart/form-data to `deposition['links']['files']`
   - Returns list of upload responses
   - Logs progress per-file (size, upload time)

   **`publish_deposition(deposition: dict, *, target: str, zenodo_token: str, dry_run: bool = False) -> dict`**
   - If dry_run: log "Would publish" and return without action
   - Otherwise POST to `deposition['links']['publish']`
   - Returns the published deposition (with `doi` field populated)

   **`main(argv: list[str] | None = None) -> int`** CLI entry point:
   - `--repo-id` (default `matheus-rech/icskg-br-processed`)
   - `--revision` (required, e.g., `v0.1.0`)
   - `--target` (`sandbox` or `production`, required — no default to force explicit choice)
   - `--zenodo-json` (default `.zenodo.json`)
   - `--dry-run` (skip publish step but still create deposition + upload)
   - `--working-dir` (default `~/.cache/icskg-zenodo/{revision}`)
   - Reads `ZENODO_TOKEN_SANDBOX` or `ZENODO_TOKEN` env var depending on `--target`
   - Reads `HF_TOKEN` env var for the HF fetch
   - Wires `load_zenodo_metadata` → `fetch_from_hf` → `create_zenodo_deposition` → `upload_files` → `publish_deposition`
   - On success, prints the minted DOI and the deposition URL
   - Returns 0 on success, 1 on any failure

2. **Create tests/test_mirror_to_zenodo.py** with mocked HTTP:
   - `test_load_zenodo_metadata_rejects_placeholders` — load a fixture .zenodo.json with `[Author Name]`, assert ValueError
   - `test_load_zenodo_metadata_accepts_real_metadata` — load a clean fixture, assert dict returned
   - `test_create_zenodo_deposition_uses_sandbox_url_when_target_is_sandbox` — mock requests.post, assert URL contains `sandbox.zenodo.org`
   - `test_create_zenodo_deposition_uses_production_url_when_target_is_production` — same but production

   - `test_main_requires_explicit_target` — call main without --target, assert SystemExit (argparse)

3. **Conventions** as before: pathlib, %-style logging, type hints, docstrings.
