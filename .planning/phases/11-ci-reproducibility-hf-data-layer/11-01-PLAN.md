From hashlib (stdlib):
```python
import hashlib
def sha256_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()
```

Namespace assignment heuristic (used in duckdb_to_parquet_tree):
```python
NAMESPACE_RULES = [
    # (substring match in table name, namespace)
    ("dimension_score", "dimensions"),
    ("cuds", "dimensions"),
    ("lcogs", "lcogs"),
    ("municipal_health", "panel"),  # the 50,130-row main table
    ("municipality_lookup", "panel"),
    ("dimension_metadata", "panel"),
    ("validation_report", "panel"),
    ("imputation_log", "panel"),
    # Source tables fall through to source_tables/ namespace
]
def assign_namespace(table_name: str) -> str:
    for substr, ns in NAMESPACE_RULES:
        if substr in table_name.lower():
            return ns
    return "source_tables"
```

<gotchas>
- The DuckDB file at /Volumes/home/DataLake/30_models/icskg_br/icskg_br_export.duckdb is on an SMB mount. SMB has flaky long-running file handles. Open the connection in read_only mode and copy each table to a LOCAL working directory (e.g., ~/.cache/icskg-publish/{version}/) before running SHA256 — do not stream parquet directly to a remote path.
- Some DuckDB tables in icskg_br_export.duckdb may be views, not base tables. Use `SELECT table_name, table_type FROM information_schema.tables WHERE table_schema='main'` and only export tables (skip views, OR materialize views via CREATE TABLE AS SELECT into a temp DuckDB before export). The publish script must log every table it skips and why.
- DuckDB DECIMAL columns serialize to parquet as fixed-precision DECIMAL. Some downstream pandas readers default to float64 — that's fine for analysis but the manifest should record the original DuckDB types.
- HF private datasets require an HF_TOKEN with write permission. The token must come from huggingface_hub.HfFolder.get_token() (which reads ~/.cache/huggingface/token) OR from the HF_TOKEN env var. Never hardcode.
- huggingface_hub.upload_folder uploads in alphabetical order; large parquet files may take several minutes over residential upload bandwidth. Use commit_message="bootstrap v0.1.0 from {source_sha256[:12]}" so the HF commit history is informative.
- The dataset README.md auto-generated by this script must follow HF Dataset Card schema (YAML frontmatter with license, language, tags, size_categories, configs). Without it the HF Dataset Viewer will show errors.
- create_tag is idempotent only via try/except RepositoryNotFoundError + HfHubHTTPError. Wrap it.
</gotchas>

   - Returns one of: "panel", "dimensions", "lcogs", "source_tables"

   **`duckdb_to_parquet_tree(source_duckdb: Path, working_dir: Path, *, compression_level: int = 6) -> dict`**
   - Opens DuckDB read-only via `duckdb.connect(str(source_duckdb), read_only=True)`
   - Queries `information_schema.tables WHERE table_schema='main'` to enumerate all base tables (skip views, log skipped views with reason)
   - For each table:
     - Determines namespace via `assign_namespace(table_name)`
     - Creates `working_dir/{namespace}/` if not exists (parents=True, exist_ok=True)

     - Captures row count, column count, schema (as list of dicts), file size, file SHA256
   - Returns a dict: `{"tables": [...], "skipped_views": [...], "compression_level": ...}`
   - Uses `logger.info` with %-style formatting (no f-strings) for all status output, with section banners (`─` separator) before each table batch

   **`build_manifest(source_duckdb: Path, conversion_result: dict, dataset_name: str, dataset_version: str) -> dict`**
   - Builds the manifest dict matching the schema in `<interfaces>` (above)
   - Computes `source_duckdb.sha256` and `size_bytes` for the source file
   - `generated_at` uses `datetime.now(timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")`
