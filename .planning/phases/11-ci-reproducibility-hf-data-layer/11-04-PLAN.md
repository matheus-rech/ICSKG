<interfaces>
The walkthrough's command sequence must match exactly what `--from-hf` does, end-to-end:

```bash
# Step 1: Clone the repo
git clone https://github.com/matheus-rech/ICSKG.git
cd ICSKG

# Step 2: Install Python 3.12 (if not present)
# - macOS: brew install python@3.12
# - Linux: apt install python3.12 python3.12-venv
# - Or use uv: curl -LsSf https://astral.sh/uv/install.sh | sh

# Step 3: Install project dependencies
uv sync               # if using uv (recommended)
# OR
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e .
pip install pytest

# Step 4: Set HuggingFace token (private dataset access)
# Get a read-scoped token from https://huggingface.co/settings/tokens
export HF_TOKEN=hf_yourtoken
# OR (better for repeat use)
huggingface-cli login

# Step 5: Run unit tests (sanity check)
python -m pytest tests/ -v --tb=short

# Step 6: Build the database from HuggingFace
python -m database.build_database_v3 \
  --from-hf v0.1.0 \
  --hf-repo-id mmrech/icskg-br-processed \
  --processed-dir data_sources/processed \
  --db-dir database \
  --years 2015 2023

# Step 7: Verify
sqlite3 database/icskg_br.sqlite "SELECT COUNT(*) FROM municipal_health"
# Expected: 50130
```

Expected timing on a 2023 MacBook Pro M2 / Ubuntu equivalent:
- Step 3 (uv sync): ~2 min
- Step 5 (pytest): ~30 sec
- Step 6 (HF download + build): ~5-8 min on first run, ~1-2 min on cache hit
- Total: 8-12 min first run, 4-5 min subsequent runs
