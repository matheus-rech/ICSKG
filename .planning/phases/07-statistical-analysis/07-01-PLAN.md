<objective>
Run six two-way fixed-effects panel regressions of CUDS on each LCoGS outcome using linearmodels PanelOLS, with cluster-robust standard errors at municipality level, Hausman FE-vs-RE selection tests, polynomial dose-response analysis, and sensitivity analyses comparing arithmetic vs geometric mean CUDS and excluding high-missingness municipalities.

Purpose: This is the primary hypothesis-testing phase -- it quantifies whether urban development (CUDS) predicts surgical system performance (LCoGS indicators) after controlling for unobserved municipality and time heterogeneity.
Output: Regression tables, Hausman test results, dose-response curves, sensitivity analysis results -- all saved to results/ for the publication package.
</objective>

    - Read dimension_scores and lcogs_indicators from SQLite, inner-join on (cod_ibge, year)
    - Set MultiIndex (cod_ibge, year) as required by linearmodels PanelOLS

    **Core regression function** `run_panel_regressions(panel)`:
    - For each of the 6 LCoGS outcomes, run PanelOLS with:
      - dependent: outcome column
      - exog: cuds (+ constant via add_constant from statsmodels or linearmodels)
      - entity_effects=True (municipality FE), time_effects=True (year FE)
      - .fit(cov_type="clustered", cluster_entity=True) for municipality-level clustering (per STAT-02)
    - Drop rows with NaN in the dependent variable per-regression (each outcome has different missingness)
    - Return dict mapping outcome name to PanelOLS result object
    - Log N observations, R-squared within, coefficient and p-value for each regression

    **Hausman test function** `run_hausman_tests(panel)`:
    - For each outcome: fit both FE (PanelOLS with entity_effects) and RE (RandomEffects from linearmodels)
    - Compute Hausman test: H = (b_FE - b_RE)' * (V_FE - V_RE)^(-1) * (b_FE - b_RE) with chi2 df=k
    - Use scipy.stats.chi2.sf(H, df=k) for p-value
    - If p < 0.05, preferred_model = "FE"; else "RE" (but note that FE is used regardless for robustness)
    - Return DataFrame with columns: outcome, chi2_stat, p_value, df, preferred_model
    - Save to results/hausman_test.csv

    **Result export function** `save_regression_tables(results, out_dir)`:
    - For each regression result, extract: coefficient, std_error, t_stat, p_value, conf_int, n_obs, r2_within, r2_between, r2_overall
    - Save as CSV to results/regression_tables/{outcome_name}.csv
    - Also save a combined summary CSV with one row per outcome

    **CLI main()** with --db-path and --out-dir arguments.
    Follow patterns from compute_dimensions.py: stage banners, logger.info with %-style, sys.exit(main()).

    **Important linearmodels specifics:**
    - `from linearmodels.panel import PanelOLS, RandomEffects`
    - PanelOLS requires DataFrame with MultiIndex (entity, time)
    - Use `sm.add_constant()` from statsmodels for constant term, or `check_rank=False` if needed
    - .fit(cov_type="clustered", cluster_entity=True) for STAT-02 cluster-robust SEs
    - Access results via: result.params, result.pvalues, result.std_errors, result.conf_int(), result.summary
    - result.nobs for observation count, result.rsquared_within for R-squared within
