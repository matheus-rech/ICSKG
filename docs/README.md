# docs/

This directory contains the ICSKG-BR study documentation:

| File | Description |
|------|-------------|
| `ICSKG-BR_Methodology_and_Gap_Analysis.md` | Full methodology, CIMI dimension definitions, gap analysis framework, and reproducibility instructions |
| `ICSKG-BR_Study_Protocol_v2.docx` | Formal study protocol (DOCX; see note below) |
| `ICSKG-BR_Variable_Cookbook_v2.xlsx` | Variable definitions, coding, sources, and transformation rules (Excel workbook) |
| `ICSKG-BR_Technical_Cookbook_v2.docx` | Step-by-step technical instructions for data extraction and analysis (DOCX; see note below) |

> **Note:** The `.docx` and `.xlsx` files are distributed as part of the
> **ICSKG-BR_Final_Package_v4.zip** release bundle.  
> The methodology content is also available in machine-readable form in
> `ICSKG-BR_Methodology_and_Gap_Analysis.md` (this directory).
