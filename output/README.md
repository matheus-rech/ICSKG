# output/

This directory contains the geospatial outputs of the LCoGS-1 bellwether analysis
produced by `extract_lcogs1.py`.

## Files

| File | Description |
|------|-------------|
| `lcogs1_bellwether_map.png` | Brazil choropleth – bellwether procedure rates per 100 000 population |
| `lcogs1_bellwether_map_detail.png` | Binary attainment map (meets / does not meet LCoGS-1 benchmark) |
| `lcogs1_bellwether_rates.csv` | Municipality-level bellwether procedure rates |
| `lcogs1_bellwether_gap.csv` | Gap to LCoGS-1 benchmark (5 000 procedures / 100 000 / year) |

> Files are generated by running:
> ```bash
> python extract_lcogs1.py --year 2023
> ```
