# analysis/results/

This directory contains all outputs generated by `analysis/icskg_analysis_pipeline.py`.

## Figures (4)

| File | Description |
|------|-------------|
| `figure1_icskg_distribution.png` | Histogram – distribution of ICSKG composite scores |
| `figure2_cimi_dimensions_boxplot.png` | Box plot – distribution of all 9 CIMI dimension scores |
| `figure3_temporal_trend.png` | Line chart – mean ICSKG score 2013–2024 |
| `figure4_correlation_heatmap.png` | Heatmap – correlation matrix of CIMI dimensions |

## Tables (8)

| File | Description |
|------|-------------|
| `table1_descriptive_statistics.csv` | Descriptive statistics for all dimensions |
| `table2_correlation_matrix.csv` | Pearson correlation matrix |
| `table3_top10_municipalities.csv` | Top 10 municipalities by ICSKG score |
| `table4_bottom10_municipalities.csv` | Bottom 10 municipalities by ICSKG score |
| `table5_quartile_means.csv` | Mean dimension scores by ICSKG quartile |
| `table6_annual_means.csv` | Annual mean scores for all dimensions (2013–2024) |
| `table7_missing_data_summary.csv` | Missing-data summary per dimension |
| `table8_dimension_metadata.csv` | Dimension keys and labels |

## Panel dataset

| File | Description |
|------|-------------|
| `icskg_panel_2013_2024.csv` | Full longitudinal panel – all municipalities, 2013–2024, all CIMI dimensions + composite ICSKG score |

> Files are generated by running:
> ```bash
> python analysis/icskg_analysis_pipeline.py
> ```
